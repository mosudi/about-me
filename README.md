# About Me - Moshood Mosudi

A clean, semantic personal "About Me" webpage built with pure HTML5 as part of my web development bootcamp foundation.

## 🚀 Features
- **Semantic HTML5 Structure**: Proper heading hierarchy (`<h1>` to `<h3>`), `<header>`, `<main>`, `<section>`, and `<footer>` elements.
- **Profile & Introduction**: Background, motivation, and coding journey.
- **Hobbies & Interests**: Structured unordered list (`<ul>`).
- **Learning Milestones**: Ordered list (`<ol>`) outlining tech goals.
- **External Connections**: Links to GitHub profile, MDN Web Docs, and LinkedIn.
- **Zero CSS / Pure HTML**: Strictly focused on content structure and accessibility.

## 📁 Project Structure
```text
├── about-me.html    # Primary assignment page
├── index.html       # Entry point for GitHub Pages
├── profile.png      # Profile picture
└── README.md        # Project documentation
```

## 🌐 Live Preview
You can view this page locally by opening `index.html` or `about-me.html` in any web browser, or via GitHub Pages.
